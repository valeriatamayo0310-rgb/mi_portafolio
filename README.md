# Mi portafolio — Valeria Tamayo

**Autora:** Valeria Tamayo Torres (valeriatamayo0310-rgb)

## Descripción del proyecto

Este repositorio contiene mi portafolio como diseñadora gráfica. Es una marca maximalista y expresiva, con colores fuertes, formas divertidas y una dosis de caos intencional.

Incluye dos páginas hechas en HTML con sus imágenes, tipografías y videos en la carpeta `assets/`:

- `index.html`: mi landing de CV de una sola página, con inicio, sobre mí, proyectos, habilidades, formación y contacto.
- `design.html`: la referencia visual de mi sistema de diseño, con colores, letras, botones y componentes.

El diseño visual se basa en el archivo `DESIGN.md` y el contenido de la landing en `CV.md`.
